# Теория по параметру

Параметр — это число, от которого зависит уравнение. Мы ищем значения этого числа, при которых меняется **количество решений**. Начнём со знакомого примера, а затем посмотрим, почему на графике важна даже одна пропущенная точка.

## Знакомое уравнение уже содержит параметр

В уравнении $ax=b$ число $a$ можно считать параметром:

| Условие | Решения |
| :-- | :-- |
| $a\ne0$ | Один корень: $x=b/a$ |
| $a=0$, $b=0$ | Любое действительное число |
| $a=0$, $b\ne0$ | Корней нет |

Так устроены и более сложные задачи: надо найти границы, на которых число решений меняется. Например, для квадратного уравнения $ax^2+bx+c=0$ **при $a\ne0$** их задаёт дискриминант $D=b^2-4ac$: два корня при $D>0$, один при $D=0$, ни одного при $D<0$. Если $D\ge0$, корни равны $x=(-b\pm\sqrt D)/(2a)$.

## График и выколотая точка

Рассмотрим пересечения прямой $y=kx$ с параболой $y=-x^2-1$, **из которой исключена точка $(2;-5)$**. Передвиньте $k$ и найдите положения, в которых остаётся ровно одно пересечение. Попробуйте сначала $k=2$ и $k=-2$, затем $k=-2{,}5$.

<div class="parameter-demo"><img src="./assets/math/parameter-poster.svg" alt="Парабола с исключённой точкой (2; −5) и прямая y = −2,5x, пересекающая график ещё в одной точке" loading="lazy"></div>

Для полной параболы точки пересечения удовлетворяют $x^2+kx+1=0$. При $k=\pm2$ дискриминант равен нулю: прямая касается графика и даёт один корень. Есть ещё одно положение: при $k=-2{,}5$ уравнение имеет корни $x=0{,}5$ и $x=2$, но второй запрещён. На исходном графике остаётся одна точка пересечения.

**Ответ для одного пересечения:** $k\in\{-2{,}5;-2;2\}$.

> [!tip] Главная мысль
> После преобразования формулы проверяйте область допустимых значений. Удалённая точка может изменить число решений, даже когда сама парабола выглядит почти прежней.

## Проверьте себя

Почему при $k=-2{,}5$ два корня квадратного уравнения дают только одно пересечение на рисунке?

> [!tip]- Ответ
> Второй корень $x=2$ попадает в исключённую точку $(2;-5)$, которой нет на исходном графике.
