# Демонстрационный модуль математики

## Функции

Начните с [[Математика/Теория/04 Функции/04.0 Общая информация\|общей информации о функциях]]. Затем в проводнике слева переходите к свойствам, графикам и видам функций.

## Задачи с параметром

Перед решением задач изучите [[Математика/_Разборы задач/11 класс ЕГЭ/№ 19 Параметр/Теория по параметру\|теорию параметров]], затем откройте [[Математика/_Разборы задач/11 класс ЕГЭ/№ 19 Параметр/Графиками\|графический разбор]].

## Тренировочные задания по базовой арифметике

Раздел содержит задания по дробям, процентам, степеням, корням и другим базовым темам. [[Математика/Тренировочные задания/01 Базовая арифметика/01.1 Обыкновенные дроби\|Начните с обыкновенных дробей]] и выбирайте следующие темы в проводнике слева.
