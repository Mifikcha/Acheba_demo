### Пример 7)

![[_Resours/Pasted image 20240926190144.png]]

Аналогично предыдущим, меняются только условия. В случае этого задания нужно 3 условия:

1) Чтобы первое число не было равно 0, иначе число не будет восприниматься как пятизначное и мы получим неправильный ответ.
2) Чтобы в числе было ровно 2 тройки.
3) Чтобы никоим образом мы не встретили внутри числа одну из следующих комбинаций: `[12 21 23 32 52 25 72 27]`.

<div class="python-checker" data-title="Пример 7" data-code="alp = &#x27;012345678&#x27;&#10;count = 0&#10;for l1 in alp:&#10;    for l2 in alp:&#10;        for l3 in alp:&#10;            for l4 in alp:&#10;                for l5 in alp:&#10;                    number = l1 + l2 + l3 + l4 + l5&#10;                    if number[0] != &#x27;0&#x27;:&#10;                        if number.count(&#x27;3&#x27;) == 2:&#10;                            if all(x not in number for x in &#x27;12 21 23 32 52 25 72 27&#x27;.split()):&#10;                                count += 1&#10;print(count)"></div>

Разберемся с третьим условием подробнее.

```python
if all(x not in number for x in '12 21 23 32 52 25 72 27'.split()):
```

Этот кусок кода проверяет, что в числе `number` нет запрещенных комбинаций `"12"`, `"21"`, `"23"`, `"32"`, `"52"`, `"25"`, `"72"`, `"27"`.

Это работает так: `'12 21 23 32 52 25 72 27'.split()` превращает строку в список: `['12', '21', '23', '32', '52', '25', '72', '27']`. Затем, в `for x in ['12', '21', '23', '32', '52', '25', '72', '27']` мы перебираем каждую запрещенную последовательность (`x`). `x not in number`: тут проверяем, содержится ли `x` в `number`. Если `number = "12345"`, `"12"` есть в `number`, значит `x not in number` → ложь.  Если `number = "34567"`, `"12"` нет, значит `x not in number` → истина.

`all([...])` проверяет, **что все элементы** списка дают `True`, т.е. ни одной запрещенной комбинации **нет** в числе.

### Пример работы

### Пример 1) (Запрещенная комбинация есть)

```python
number = "12345"
```
- `'12' in "12345"` → `True`
- `'21' in "12345"` → `False`
- `'23' in "12345"` → `True`
- Остальные комбинации не проверяются, так как `all([...])` уже **не выполняется**.
- **Условие не проходит, число не учитывается**.

### Пример 2) (Все запрещенные комбинации отсутствуют)

```python
number = "30456"
```
- `'12' not in "30456"` → `True`
- `'21' not in "30456"` → `True`
- `'23' not in "30456"` → `True`
- `'32' not in "30456"` → `True`
- `'52' not in "30456"` → `True`
- `'25' not in "30456"` → `True`
- `'72' not in "30456"` → `True`
- `'27' not in "30456"` → `True`
- **Все элементы вернули `True`, значит `all([...]) == True`**, и число засчитывается.

Таким образом, каждый из нас - булочка с корицей,,,

**_Ответ:_** 3352.
