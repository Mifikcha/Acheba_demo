# Цикл for и range

`for` удобен, когда понятно, что именно надо перебрать.

```python
for ch in "code":
    print(ch)
```

Для чисел часто используют `range()`.

```python
for i in range(1, 4):
    print(i)
```

Этот код выведет `1`, `2`, `3`. Правая граница в `range` не включается, поэтому для диапазона до `finish` включительно пишут `range(start, finish + 1)`.

Если вызов `range(1, 4)` выглядит как вызов функции, так и есть: подробнее в [[04.1 Вызов функции]] и [[04.2 Аргументы функции]].

### Задачи

1. Выведи числа от `1` до `5` через `for`.
2. Выведи квадраты чисел от `1` до `n`.
3. Перебери символы строки через `for`.

### Предскажи вывод

```python
for i in range(3):
    print(i)
```

> [!tip]- Ответ
> Будет `0`, `1`, `2`.
