# Цикл while

Цикл нужен, когда одно и то же действие надо повторить несколько раз.

`while` читается как «пока условие истинно».

```python
i = 1
while i <= 3:
    print(i)
    i = i + 1
```

У цикла обычно есть три части:

| Часть | Пример |
|---|---|
| начальное значение | `i = 1` |
| условие продолжения | `while i <= 3:` |
| изменение счетчика | `i = i + 1` |

Если условие в `while` пока непонятно, вернись к [[05.1 Сравнения]] и [[05.8 Условие if]].

### Задачи

1. Выведи числа от `1` до `5`.
2. Выведи числа от `3` до `1`.
3. Напиши функцию, которая печатает `Hello!` заданное количество раз.

### Предскажи вывод

```python
i = 2
while i <= 4:
    print(i)
    i = i + 1
```

> [!tip]- Ответ
> Будет `2`, `3`, `4`.
