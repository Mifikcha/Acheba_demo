# Накопитель строк

Строку тоже можно собирать постепенно.

```python
result = ""
i = 1
while i <= 3:
    result = result + str(i)
    i += 1

print(result)  # 123
```

Пустая строка `""` — удобное начальное значение для сборки текста.

Число нельзя напрямую склеить со строкой, поэтому используется `str(i)`. Если это место мутное, смотри [[03.1 Строка это текст]] и [[03.4 Склеивание строк]].

### Задачи

1. Собери строку `"12345"` циклом.
2. Собери строку из чисел диапазона `start..finish`.
3. Собери строку из одинакового символа `times` раз.

### Мини-проверка

```python
result = ""
i = 3
while i <= 5:
    result += str(i)
    i += 1

print(result)
```

> [!tip]- Ответ
> Будет `345`.
