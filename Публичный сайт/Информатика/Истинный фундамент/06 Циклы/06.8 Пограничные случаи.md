# Пограничные случаи

Пограничный случай — это входные данные на краю нормальной ситуации.

Для подстроки такими краями будут:

| Случай | Почему опасно |
|---|---|
| `length < 0` | отрицательная длина не имеет смысла |
| `index < 0` | начало до строки |
| `index >= len(text)` | начало после строки |
| `index + length > len(text)` | конец вылезает за строку |

Такие проверки обычно пишут через `if` и логические операторы.

Если трудно читать длинное условие, смотри [[05.5 Оператор and]] и [[05.6 Оператор or]].

### Задачи

1. Проверь, что индекс не отрицательный.
2. Проверь, что индекс меньше длины строки.
3. Проверь, что `index + length` не выходит за конец строки.

### Мини-проверка

```python
text = "abc"
index = 2
length = 2
print(index + length <= len(text))
```

> [!tip]- Ответ
> Будет `False`.
