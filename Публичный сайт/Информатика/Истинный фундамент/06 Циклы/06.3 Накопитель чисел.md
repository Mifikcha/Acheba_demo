# Накопитель чисел

Накопитель — это переменная, которая собирает ответ по кусочкам.

Для суммы стартуют с `0`:

```python
total = 0
i = 1
while i <= 3:
    total = total + i
    i += 1
```

Для произведения стартуют с `1`, потому что умножение на `1` ничего не портит.

```python
result = 1
result = result * 2
result = result * 3
```

Если не помнишь, почему результат можно хранить в переменной, смотри [[03.9 Выражения в переменных]].

### Задачи

1. Посчитай сумму чисел от `1` до `n`.
2. Посчитай произведение чисел от `start` до `finish`.
3. Посчитай сумму только четных чисел от `1` до `n`.

### Предскажи вывод

```python
total = 0
i = 2
while i <= 4:
    total += i
    i += 1

print(total)
```

> [!tip]- Ответ
> Будет `9`.
