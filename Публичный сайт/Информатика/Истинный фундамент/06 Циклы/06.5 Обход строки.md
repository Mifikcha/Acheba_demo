# Обход строки

Строку можно проходить по символам через индекс.

```python
word = "Arya"
i = 0
while i < len(word):
    print(word[i])
    i += 1
```

Индексы начинаются с `0`, поэтому последний индекс равен `len(word) - 1`.

```python
word = "Hex"
print(word[0])  # H
print(word[2])  # x
```

Если индексы ещё плавают, вернись к [[03.14 Индексы строк]].

### Задачи

1. Выведи все символы строки по одному.
2. Выведи символы строки в обратном порядке.
3. Верни первый и последний символ строки.

### Предскажи вывод

```python
text = "cat"
i = 0
while i < len(text):
    print(text[i])
    i += 1
```

> [!tip]- Ответ
> Будет `c`, `a`, `t`.
