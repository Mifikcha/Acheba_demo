# Звезда 001. Три цифры наоборот

Дано трёхзначное положительное число `n`. Напиши `reverse3(n)`, возвращающую число с цифрами в обратном порядке. Строки использовать нельзя.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `reverse3(123)` → `321`
- `reverse3(907)` → `709`
- `reverse3(450)` → `54`

> [!tip]- Подсказка 1
> Последняя цифра — `n % 10`.

> [!tip]- Подсказка 2
> После `n // 10` последняя цифра исчезает.
