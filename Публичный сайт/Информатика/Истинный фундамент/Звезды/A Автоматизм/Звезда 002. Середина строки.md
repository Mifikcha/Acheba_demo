# Звезда 002. Середина строки

Напиши `middle(text)`: для нечётной длины вернуть один центральный символ, для чётной — два центральных.

Функция должна именно вернуть результат, а не печатать его. Сохраняй имя функции и порядок аргументов из условия: проверка будет вызывать её напрямую.

## Примеры

- `middle('abcde')` → `'c'`
- `middle('python')` → `'th'`
- `middle('x')` → `'x'`

> [!tip]- Подсказка 1
> Центральный индекс связан с `len(text) // 2`.

> [!tip]- Подсказка 2
> Для чётной длины нужны позиции `m - 1` и `m`.
