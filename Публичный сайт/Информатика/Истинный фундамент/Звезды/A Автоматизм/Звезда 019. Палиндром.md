# Звезда 019. Палиндром

**Попробуйте сами:** допишите одну строку в редакторе справа и нажмите «Запустить». Слово «топот» читается одинаково с обоих концов, а «питон» — нет. Что должна вернуть функция для пустой строки?

Функция должна **вернуть** результат, а не печатать его. Сохраняйте имя функции и её аргумент: проверки вызывают её напрямую. При первом запуске Python может потребоваться время для загрузки среды.

## Примеры

- `is_palindrome('level')` → `True`
- `is_palindrome('python')` → `False`
- `is_palindrome('а')` → `True`

> [!tip]- Подсказка 1
> Срез умеет разворачивать строку.

> [!tip]- Подсказка 2
> Сравни строку с `text[::-1]`.
