# Множества

Множество хранит только уникальные элементы.

```python
digits = {1, 2, 2, 3}
print(digits)  # {1, 2, 3}
```

Если нужно быстро понять, есть ли элемент, или посчитать разные элементы, часто нужен `set`.

```python
seen = set()
seen.add("a")
seen.add("a")
print(len(seen))  # 1
```

Строку или список можно превратить во множество:

```python
print(set("banana"))  # {'b', 'a', 'n'}
```

Если не помнишь `in`, смотри [[05.3 Предикаты]].

### Операции

```python
a = {1, 2, 3}
b = {3, 4}

print(a & b)  # пересечение: {3}
print(a | b)  # объединение: {1, 2, 3, 4}
print(a - b)  # разность: {1, 2}
```

### Задачи

1. Посчитай количество различных цифр в числе.
2. Посчитай количество различных слов в строке.
3. Проверь, есть ли в двух списках общий элемент.

### Предскажи вывод

```python
s = set("1212")
print(len(s))
print("3" in s)
```

> [!tip]- Ответ
> Сначала `2`, потом `False`.
