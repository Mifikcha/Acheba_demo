# Приоритет операций и скобки

> [!note] Зачем это нужно:
> Скобки решают, что именно считается первым. В №16 это особенно заметно: одна скобка может полностью поменять ответ.

Питон считает выражения по тем же правилам, что и школьная математика:

1. сначала скобки;
2. потом степень;
3. потом умножение, деление, целая часть и остаток;
4. потом сложение и вычитание.

```
print(2 + 2 * 2)      # 6
print((2 + 2) * 2)    # 8
print(2 ** 3 * 2)     # 16
print(2 ** (3 * 2))   # 64
```

Если есть сомнение, ставь скобки. На экзамене понятная запись лучше, чем красивая.

> [!warning] Скобки меняют смысл
> `print((f(2024) + 2 * f(2023)) // f(2022))` и `print(f(2024) + 2 * f(2023) // f(2022))` — это разные вычисления. Такой тип ошибки встречается в [[№16 Простая рекурсия]].

### Задачи

1. Расставь скобки так, чтобы `70 * 3 + 4 / 8 + 2` сначала считало `3 + 4` и `8 + 2`.
2. Напиши программу для выражения: сумма чисел `15` и `25`, умноженная на `3`.
3. Напиши программу для выражения: квадрат разности `20` и `7`.
4. Напиши две программы: одна считает `2 + 3 * 4`, другая считает `(2 + 3) * 4`.
5. Объясни, почему ответы разные.

Если можешь поставить скобки так, чтобы программа считала именно твою мысль, идем дальше.
