# Дробные числа

> [!note] Зачем это нужно:
> Дроби иногда появляются в вычислениях, но в первых программных задачах ЕГЭ чаще надежнее держаться целых чисел.

У дробных чисел в Питоне есть особенность:

```
print(0.2 + 0.1)
```

Можно увидеть:

```
0.30000000000000004
```

Это не ошибка. Компьютер хранит дробные числа приближенно. Для первых задач ЕГЭ чаще всего лучше работать с целыми числами, остатками и целой частью от деления.

Если дроби все-таки нужны, результат можно округлить:

```
print(round(0.2 + 0.1, 2))
```

> [!warning] Осторожно с `/`
> `/` дает дробный результат. Если нужна целая часть деления, используй `//`. Если нужен остаток, используй `%`.

### Задачи

1. Выведи `0.39 * 0.22`.
2. Выведи `0.1 + 0.2`.
3. Округли результат `0.1 + 0.2` до двух знаков.
4. Сравни `7 / 2` и `7 // 2`.
5. Объясни, почему в задачах с цифрами числа удобнее `%` и `//`, а не `/`.
