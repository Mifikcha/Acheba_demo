# Составные выражения

> [!note] Зачем это нужно:
> В реальных разборах часто одна строка кода считает сразу несколько действий, например в [[№16 Простая рекурсия]] и [[№24 Строки 2]].

Операции можно соединять:

```
print(2 * 4 * 5 * 10)
```

Питон сначала вычисляет выражение, потом выводит результат.

Если хочется сохранить промежуточный результат и не повторять кусок вычисления, это делается через [[03.5 Что такое переменная]].

Еще пример:

```
print(8 / 2 + 5 - -3 / 2)
```

Вручную считать не нужно. Задача программы — посчитать за нас.

### Задачи

1. Выведи результат `8 / 2 + 5 - -3 / 2`.
2. Выведи результат `100 - 25 * 3`.
3. Выведи результат `6 * 7 + 8 * 9`.
4. Выведи результат `2 ** 5 + 3 ** 3`.
5. Выведи результат `123 // 10 + 123 % 10`.

### Мини-челлендж на 3 минуты

Дано число `472`. Одной программой выведи:

1. последнюю цифру;
2. предпоследнюю цифру;
3. сумму этих двух цифр.
