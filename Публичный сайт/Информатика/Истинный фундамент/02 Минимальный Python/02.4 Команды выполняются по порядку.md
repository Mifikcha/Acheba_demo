# Команды выполняются по порядку

> [!note] Зачем это нужно:
> В разборах ЕГЭ код всегда читается сверху вниз как рецепт решения.

Программа — это набор команд. Обычно одна команда пишется на одной строке.

```
print("Первая")
print("Вторая")
print("Третья")
```

Результат будет в том же порядке:

```
Первая
Вторая
Третья
```

Можно написать две команды в одной строке через `;`, но так почти никогда не надо делать:

```
print("Первая"); print("Вторая")
```

Для учебы и экзамена лучше писать понятно: одна команда — одна строка.

### Задачи

1. Выведи числа `1`, `2`, `3`, каждое на новой строке.
2. Поменяй порядок команд так, чтобы программа вывела:

```
старт
решение
ответ
```

3. Напиши пять команд вывода. Перед каждой поставь комментарий с номером шага.

### Задача на ошибку

Что не так с программой?

```
print("старт")
print("ответ")
print("решение")
```

Исправь порядок строк так, чтобы получился нормальный ход решения.
