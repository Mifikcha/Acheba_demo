# Оператор и операнд

> [!note] Зачем это нужно:
> Когда в условии много знаков, надо видеть не “кашу”, а действия и числа, к которым они применяются.

В выражении:

```
print(8 + 2)
```

`+` — оператор, то есть знак действия. `8` и `2` — операнды, то есть значения, с которыми действие выполняется.

Операция с двумя значениями называется бинарной:

```
print(6 * 7)
```

Операция с одним значением называется унарной:

```
print(-5)
```

Минус перед числом делает число отрицательным.

### Задачи

1. Выведи `6 - -81`.
2. Выведи `-10 + 3`.
3. Выведи `5 * -4`.
4. В выражении `12 // 5` назови оператор и два операнда.
5. В выражении `-9` объясни, почему минус работает с одним числом.

### Предскажи вывод

```
print(6 - -81)
print(6 - 81)
```

Почему ответы разные?

> [!tip]- Ответ
> Первое - Питон воспринимает это как `6 - (-81) = 87`, а во втором случае - `6 - 81 = -75`
