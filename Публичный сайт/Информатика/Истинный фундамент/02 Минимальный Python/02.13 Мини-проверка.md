# Мини-проверка

Сначала пройди короткие шаги в тренажёре. Затем собери итоговую программу из шести строк.

Если путаешь, где нужна строка, а где вычисление, вернись к [[03.1 Строка это текст]] и [[Типы данных]].

### Задачи

1. строку `Начало`;
2. результат выражения `2 + 2 * 2`;
3. результат выражения `(2 + 2) * 2`;
4. последнюю цифру числа `2026`;
5. десятки числа `2026`;
6. строку `Готово`.

### Подсказка к итогу

Решение не подглядывать сразу. Сначала набрать самому, запустить, исправить ошибки, потом сверить идею:

> [!tip]- Ответ
> ```
> print("Начало")
> print(2 + 2 * 2)
> print((2 + 2) * 2)
> print(2026 % 10)
> print((2026 // 10) % 10)
> print("Готово")
> ```

Дальше можно переходить к условиям, циклам и первым экзаменационным переборам.
