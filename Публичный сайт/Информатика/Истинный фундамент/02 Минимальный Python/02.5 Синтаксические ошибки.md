# Синтаксические ошибки

> [!note] Зачем это нужно:
> На экзамене ошибка в одной скобке может съесть больше времени, чем сама задача.

Синтаксис - это правила записи программы. Если нарушить правило, программа не запустится.

Примеры частых ошибок:

```
print("Привет"
```

Забыли закрыть скобку.

```
print("Привет)
```

Забыли закрыть кавычку.

```
pront("Привет")
```

Опечатка в названии команды.

Когда появляется ошибка, не надо паниковать. Сначала смотри на номер строки, потом на место рядом со стрелкой или последним показанным символом. Часто ошибка находится прямо там или на предыдущем символе.

> [!warning] Сначала чини первую ошибку
> Если Питон показывает много текста, не читай все подряд. Найди строку ошибки, почини самый очевидный символ и запусти еще раз.

### Задачи

1. Запусти программу с пропущенной закрывающей скобкой. Найди строку ошибки.
2. Запусти программу с опечаткой `pront`. Посмотри, чем это сообщение отличается от ошибки со скобкой.
3. Исправь обе программы.
4. Напиши правильную программу:

```
print("ошибка найдена")
```

Если можешь сам найти пропущенную кавычку и скобку — идем дальше.
