# Как писать аккуратно

> [!note] Зачем это нужно:
> Аккуратный код легче проверять, а значит меньше шанс потерять балл из-за мелочи.

Питон поймет и так:

```
print(3+4*5)
```

Но человеку читать неприятно. Лучше писать с пробелами:

```
print(3 + 4 * 5)
```

Скобки тоже лучше ставить не "на магии", а там, где они помогают глазам:

```
print((123 // 10) % 10)
```

Эта программа получает десятки числа `123`.

Если в выражении появляются повторяющиеся непонятные числа, смотри [[03.11 Магические числа]] и [[03.12 Константы]].

### Задачи

1. Перепиши аккуратно:

```
print(8+2*5-3)
```

2. Перепиши аккуратно:

```
print((100//10)%10)
```

3. Напиши программу, которая получает последнюю цифру числа `456`.
4. Напиши программу, которая получает десятки числа `456`.
5. Напиши программу, которая получает сотни числа `456`.
