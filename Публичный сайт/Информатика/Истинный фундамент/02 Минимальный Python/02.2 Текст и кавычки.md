# Текст и кавычки

> [!note] Зачем это нужно:
> Почти все ошибки в первых программах - это забытые кавычки, скобки и мелкие опечатки.

Текст в программе должен быть в кавычках:

```
print("Информатика")
print('Информатика')
```

Одинарные и двойные кавычки здесь работают одинаково. Главное: если открыл двойную кавычку, закрывай двойной; если открыл одинарную, закрывай одинарной.

Если не понимаешь, почему `Ответ` и `"Ответ"` для Питона разные вещи, смотри [[03.1 Строка это текст]] и [[03.5 Что такое переменная]].

Так нельзя:

```
print("Информатика')
```

Так тоже нельзя:

```
print("Информатика)
```

Во втором случае забыли закрыть кавычку.

> [!warning] Кавычки должны закрываться
> Если строка началась с `"`, она должна закончиться на `"`. Если началась с `'`, закрывай через `'`.

### Задачи

1. Выведи строку `Я решаю номер 5`.
2. Выведи строку `**_Ответ:_** 42`.
3. Специально сломай программу: убери закрывающую кавычку и запусти. Посмотри, что напишет Питон.
4. Почини программу из прошлого пункта.

### Мини-челлендж на 2 минуты

Сделай программу, которая сначала выводит текст `Ответ`, а потом на следующей строке число `2026`.
