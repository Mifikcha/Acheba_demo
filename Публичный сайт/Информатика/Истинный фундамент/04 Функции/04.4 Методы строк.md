# Методы строк

Метод — функция, которая привязана к значению.

```python
text = "Python"
print(text.upper())  # PYTHON
```

Метод вызывается через точку:

```python
значение.метод()
```

У строк есть много полезных методов:

```python
"PyThOn".lower()       # python
"python".upper()       # PYTHON
"python".replace("p", "P")  # Python
```

### Задачи

1. Выведи `"ЕГЭ".lower()`.
2. Выведи `"python".upper()`.
3. Замени в строке `"кот"` букву `к` на `р`.

### Предскажи вывод

```python
word = "Hi"
print(word.lower())
print(word)
```

> [!tip]- Ответ
> Сначала `hi`, потом `Hi`. Метод вернул новую строку, но переменную не изменил.
