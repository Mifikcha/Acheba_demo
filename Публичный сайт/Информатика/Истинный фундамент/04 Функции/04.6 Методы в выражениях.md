# Методы в выражениях

Метод можно использовать прямо внутри другого выражения.

```python
text = "Never forget"
print(text.find("f"))
```

`find` возвращает индекс первого найденного символа или подстроки.

Можно соединять результат метода с f-строкой:

```python
text = "Never, stop"
print(f"Запятая: {text.find(',')}")
```

Если индексы строк забылись, смотри [[03.14 Индексы строк]].

### Задачи

1. Найди индекс буквы `P` в строке `Python`.
2. Найди индекс подстроки `form` в строке `Informatics`.
3. Выведи `Index: 2`, где `2` получен через `.find()`.

### Предскажи вывод

```python
text = "abcabc"
print(text.find("b"))
```

> [!tip]- Ответ
> Будет `1`: `find` возвращает первое вхождение.
