# Аргументы функции

Значения внутри скобок называются аргументами.

```python
print(len("Python"))
```

У `len` один аргумент: строка.

У `pow` два аргумента:

```python
print(pow(2, 3))  # 8
```

Первый аргумент — число, второй — степень. Порядок аргументов важен.

```python
print(pow(2, 3))  # 8
print(pow(3, 2))  # 9
```

### Задачи

1. Выведи `pow(10, 2)`.
2. Выведи `round(3.14159, 2)`.
3. Проверь, чем отличаются `pow(2, 4)` и `pow(4, 2)`.

### Предскажи вывод

```python
print(pow(5, 2))
print(pow(2, 5))
```

> [!tip]- Ответ
> Будет `25`, потом `32`.
