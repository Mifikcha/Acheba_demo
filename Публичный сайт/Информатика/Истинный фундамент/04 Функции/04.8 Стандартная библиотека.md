# Стандартная библиотека

В Python уже есть много готовых функций.

```python
print(abs(-10))       # 10
print(max(3, 8, 2))   # 8
print(type("text"))   # <class 'str'>
```

Не надо помнить все функции. Важно понимать, что готовые инструменты существуют, и уметь узнавать, что они принимают и что возвращают.

`type` показывает тип значения. Если типы данных пока расплываются, смотри [[Типы данных]].

### Задачи

1. Выведи `abs(-17)`.
2. Выведи максимум из чисел `5`, `12`, `9`.
3. Выведи тип строки `"Python"`.

### Предскажи вывод

```python
print(type(42))
print(type("42"))
```

> [!tip]- Ответ
> Сначала `<class 'int'>`, потом `<class 'str'>`.
