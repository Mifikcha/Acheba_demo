# Оператор or

`or` означает «или».

```python
digit = 9
print(digit == 0 or digit == 9)
```

Все условие истинно, если истинна хотя бы одна часть.

| A | B | A or B |
|---|---|---|
| True | True | True |
| True | False | True |
| False | True | True |
| False | False | False |

Типичная ошибка:

```python
digit == (0 or 9)
```

Так не проверяют «0 или 9». Нужно сравнить переменную с каждым вариантом отдельно.

### Задачи

1. Проверь, что число равно `1` или `2`.
2. Проверь, что строка заканчивается `?` или `!`.
3. Проверь, что фамилия равна `Karstark` или `Tully`.

### Предскажи вывод

```python
x = 5
print(x == 4 or x == 5)
```

> [!tip]- Ответ
> Будет `True`.
