# Ветка else

`else` означает «иначе».

```python
def sentence_type(sentence):
    if sentence[-1] == "?":
        return "question"
    else:
        return "normal"
```

Блок `else` выполнится, если условие в `if` ложно.

Иногда `else` можно не писать, если в `if` уже был `return`:

```python
def sentence_type(sentence):
    if sentence[-1] == "?":
        return "question"
    return "normal"
```

Оба варианта нормальные. Главное — чтобы код читался понятно.

### Задачи

1. Верни `even`, если число четное, иначе `odd`.
2. Верни `yes`, если строка равна `Python`, иначе `no`.
3. Верни `positive`, если число больше нуля, иначе `not positive`.

### Предскажи вывод

```python
def check(x):
    if x == 0:
        return "zero"
    else:
        return "other"

print(check(5))
```

> [!tip]- Ответ
> Будет `other`.
