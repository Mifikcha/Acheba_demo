# Предикаты

Предикат — функция-вопрос. Она возвращает `True` или `False`.

```python
def is_even(number):
    return number % 2 == 0
```

Имена предикатов часто начинаются с `is_` или `has_`:

```python
is_even
is_empty
has_errors
```

Так код читается как обычный вопрос.

### Задачи

1. Создай `is_zero(number)`, которая проверяет `number == 0`.
2. Создай `is_python(text)`, которая проверяет `text == "Python"`.
3. Создай `has_plus(phone)`, которая проверяет первый символ номера.

### Предскажи вывод

```python
def is_big(n):
    return n > 100

print(is_big(150))
```

> [!tip]- Ответ
> Будет `True`.
