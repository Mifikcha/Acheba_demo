# Отрицание not

`not` переворачивает логическое значение.

```python
print(not True)   # False
print(not False)  # True
```

Если уже есть предикат, часто не нужна новая сложная проверка:

```python
def is_even(number):
    return number % 2 == 0

def is_not_even(number):
    return not is_even(number)
```

Двойное отрицание возвращает исходную правду:

```python
not not True  # True
```

### Задачи

1. Создай `is_not_zero(number)`.
2. Создай `is_not_python(text)` через `not`.
3. Проверь `not (10 > 5)`.

### Предскажи вывод

```python
print(not (3 > 5))
```

> [!tip]- Ответ
> Будет `True`.
