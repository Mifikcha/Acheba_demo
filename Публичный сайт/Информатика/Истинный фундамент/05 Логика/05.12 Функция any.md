# Функция any

`any` отвечает на вопрос: **есть ли хотя бы одна истинная проверка?**

```python
numbers = [1, 7, 12]
print(any(number % 2 == 0 for number in numbers))  # True
```

Выражение-генератор проверяет элементы по одному. `any` останавливается на первом `True`.

```python
words = ["cat", "python", "sun"]
print(any(len(word) > 5 for word in words))  # True
```

> [!important] Пустая коллекция
> `any([])` возвращает `False`: в пустой коллекции нет ни одной истинной проверки.

### Задачи

1. Проверь, есть ли в строке хотя бы одна цифра.
2. Проверь, есть ли в списке отрицательное число.
3. Проверь, начинается ли хотя бы одно слово с буквы `a`.

### Предскажи вывод

```python
print(any(letter == "z" for letter in "python"))
```

> [!tip]- Ответ
> Будет `False`: в слове `python` нет буквы `z`.
