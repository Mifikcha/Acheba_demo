# Логический тип

`True` и `False` — значения логического типа `bool`.

```python
result = 5 > 4
print(result)  # True
```

Сравнение — это выражение. Его результат можно сохранить в переменную, вернуть из функции или передать в `print`.

```python
def is_adult(age):
    return age >= 18
```

Если типы данных пока расплываются, смотри [[Типы данных]].

### Задачи

1. Сохрани в `answer` результат `100 % 10 == 0` и выведи.
2. Создай функцию `is_positive(number)`, которая возвращает `number > 0`.
3. Выведи `type(True)`.

### Предскажи вывод

```python
print(type(3 > 2))
```

> [!tip]- Ответ
> Будет `<class 'bool'>`.
