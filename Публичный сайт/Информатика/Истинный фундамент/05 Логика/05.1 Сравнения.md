# Сравнения

Сравнение — это вопрос, на который Python отвечает `True` или `False`.

```python
print(5 > 4)   # True
print(3 < 1)   # False
```

Основные операции:

| Запись | Что значит |
|---|---|
| `<` | меньше |
| `<=` | меньше или равно |
| `>` | больше |
| `>=` | больше или равно |
| `==` | равно |
| `!=` | не равно |

Для сравнения используют `==`, а не `=`. Одинарное `=` присваивает значение переменной. Если это смешивается, вернись к [[03.5 Что такое переменная]].

### Задачи

1. Выведи результат `10 >= 10`.
2. Выведи результат `5 == 7`.
3. Выведи результат `"abc" != "ABC"`.

### Предскажи вывод

```python
x = 4
print(x == 4)
print(x != 4)
```

> [!tip]- Ответ
> Сначала `True`, потом `False`.
