# Логика и арифметика

Логические выражения можно собирать из арифметики.

Четность проверяют через остаток от деления:

```python
def is_even(number):
    return number % 2 == 0
```

Сначала считается `number % 2`, потом результат сравнивается с нулем.

Тот же прием нужен в задачах ЕГЭ про делимость, маски, перебор и цифры числа. Если `%` подзабылся, смотри [[02.6 Числа и арифметика]].

### Задачи

1. Создай `is_last_digit_zero(number)`.
2. Создай `is_divisible_by_7(number)`.
3. Создай `is_international_phone(phone)`, которая проверяет `phone[0] == "+"`.

### Предскажи вывод

```python
print(21 % 3 == 0)
print(22 % 3 == 0)
```

> [!tip]- Ответ
> `True`, потом `False`.
