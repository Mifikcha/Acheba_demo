# Функция product

`itertools` — часть [[04.8 Стандартная библиотека|стандартной библиотеки]] Python: ничего устанавливать не нужно.

`product` собирает все варианты, выбирая по одному элементу из каждого набора.

```python
from itertools import product

for pair in product("AB", "12"):
    print(pair)
```

Получатся `('A', '1')`, `('A', '2')`, `('B', '1')`, `('B', '2')`.

Если набор один и его надо повторить, есть `repeat`:

```python
for word in product("ABC", repeat=4):
    text = "".join(word)
    print(text)
```

`product` возвращает кортежи, поэтому буквы склеивают через `"".join(...)`.

### Задачи

1. Посчитай двоичные строки длины `6`, в которых ровно две единицы.
2. Посчитай пятизначные числа из цифр `01234`, если повторы разрешены, а первая цифра не ноль.
3. Посчитай слова длины `4` из `ABC`, в которых соседние буквы различаются.
