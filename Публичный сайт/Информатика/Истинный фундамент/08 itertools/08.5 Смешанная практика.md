# Смешанная практика

Перед перебором задай два вопроса:

1. **Важен ли порядок?**
2. **Могут ли элементы повторяться?**

Это сразу отсекает лишние инструменты:

- порядок важен, повторы можно → `product`;
- порядок важен, повторов нет → `permutations`;
- порядок не важен, повторов нет → `combinations`;
- порядок не важен, повторы можно → `combinations_with_replacement`.

После выбора генератора остаётся отфильтровать варианты. Для условий «все» и «хотя бы один» используй [[05.11 Функция all|all]] и [[05.12 Функция any|any]].

```python
for code in product("01234", repeat=4):
    if code[0] != "0" and any(ch == "4" for ch in code):
        if all(code[i] != code[i + 1] for i in range(3)):
            print("".join(code))
```

### Задачи

1. На пьедестале три разных места и десять участников. Выбери нужную функцию и посчитай варианты тройки призёров.
2. Из двенадцати учеников нужно выбрать команду из четырёх. Выбери функцию и выведи первые пять команд.
3. Букет состоит из пяти цветков трёх видов; виды могут повторяться, а порядок не важен. Выбери функцию и посчитай варианты.
