# Сочетания с повторениями

`combinations_with_replacement` похожа на `combinations`: порядок не важен. Отличие одно: теперь один элемент можно брать несколько раз.

```python
from itertools import combinations_with_replacement

for scoops in combinations_with_replacement(["ваниль", "клубника"], 2):
    print(scoops)
```

Получатся:

```text
('ваниль', 'ваниль')
('ваниль', 'клубника')
('клубника', 'клубника')
```

| Функция | Порядок важен | Повторы разрешены |
| --- | :---: | :---: |
| `product` | да | да |
| `permutations` | да | нет |
| `combinations` | нет | нет |
| `combinations_with_replacement` | нет | да |

### Задачи

1. Выведи все способы выбрать три шарика мороженого из четырёх вкусов, если вкусы могут повторяться.
2. Выведи все неубывающие трёхзначные коды из цифр `1234`.
3. Для каждой функции из таблицы придумай по одной задаче и объясни выбор.
