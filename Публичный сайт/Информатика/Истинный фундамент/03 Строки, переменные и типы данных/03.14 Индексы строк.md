# Индексы строк

У каждого символа в строке есть номер — индекс.

```python
word = "Python"
print(word[0])  # P
```

Индексы начинаются с нуля.

Последний символ можно взять через `-1`:

```python
print(word[-1])  # n
```

Если выйти за границы строки, будет `IndexError`.

### Задачи

1. Из строки `ЕГЭ` выведи первый символ.
2. Из строки `Python` выведи последний символ.
3. Из строки `012345` выведи символ с индексом `3`.

### Предскажи вывод

```python
s = "abc"
print(s[1])
```

> [!tip]- Ответ
> Будет `b`, потому что `a` имеет индекс `0`, `b` — индекс `1`.
