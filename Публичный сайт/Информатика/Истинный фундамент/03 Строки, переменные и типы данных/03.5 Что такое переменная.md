# Что такое переменная

Переменная — это имя для значения.

```python
name = "Аня"
print(name)
```

Сначала справа вычисляется значение, потом оно записывается в имя слева.

```python
answer = 40 + 2
print(answer)
```

Если переменная используется в задании до объяснения, возвращайся сюда: [[Что такое переменная]].

### Задачи

1. Создай переменную `city` со строкой `Москва` и выведи ее.
2. Создай переменную `n` со значением `17` и выведи `n + 1`.
3. Создай переменную `text` со строкой `готово` и выведи ее два раза.

### Предскажи вывод

```python
x = "2 + 2"
print(x)
```

> [!tip]- Ответ
> Будет `2 + 2`. В переменной лежит строка, а не арифметическое выражение.
