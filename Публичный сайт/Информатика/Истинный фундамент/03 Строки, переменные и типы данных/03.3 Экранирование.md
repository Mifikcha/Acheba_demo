# Экранирование

Иногда внутри строки нужен невидимый символ. Например, перенос строки.

```python
print("Первая\nВторая")
```

`\n` выглядит как два символа в коде, но при выводе превращается в Enter.

Если нужно вывести сам текст `\n`, слэш надо экранировать:

```python
print("\\n")
```

Если не понимаешь, почему один слэш управляет строкой, а два слэша печатаются, потом смотри [[Экранированные последовательности]].

### Задачи

1. Одним `print` выведи `A` и `B` на разных строках.
2. Выведи текст `\n` как обычные символы.
3. Одним `print` выведи `да` и `нет` на разных строках.

### Предскажи вывод

```python
print("a\nb")
print("a\\nb")
```

> [!tip]- Ответ
> Первый `print` выведет две строки. Второй выведет одну строку `a\nb`.
