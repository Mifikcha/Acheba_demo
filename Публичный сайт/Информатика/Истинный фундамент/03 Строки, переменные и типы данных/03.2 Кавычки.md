# Кавычки

Строку можно писать в двойных или одинарных кавычках:

```python
print("Привет")
print('Привет')
```

Главное правило: чем открыли строку, тем и закрываем.

Если внутри текста нужны двойные кавычки, удобно снаружи взять одинарные:

```python
print('Он сказал "да"')
```

Если внутри нужен апостроф, удобно снаружи взять двойные:

```python
print("Dragon's mother")
```

### Задачи

1. Выведи `Он сказал "нет"`.
2. Выведи `I'm ready`.
3. Выведи `"Python"` вместе с кавычками.

### Предскажи вывод

```python
print('"Ответ"')
```

> [!tip]- Ответ
> На экране будет `"Ответ"`, потому что внешние одинарные кавычки не входят в строку, а внутренние двойные входят.
