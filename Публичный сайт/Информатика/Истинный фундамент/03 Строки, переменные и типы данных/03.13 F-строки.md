# F-строки

Склеивать строки через `+` можно, но быстро становится некрасиво:

```python
name = "Аня"
print("Привет, " + name + "!")
```

Удобнее f-строка:

```python
name = "Аня"
print(f"Привет, {name}!")
```

Все, что внутри `{}`, Питон вычисляет и подставляет в строку.

### Задачи

1. Создай `name = "Аня"` и выведи `Привет, Аня!` через f-строку.
2. Создай `n = 17` и выведи `Ответ: 17`.
3. Выведи `2 + 2 = 4`, где `4` берется из переменной.

### Предскажи вывод

```python
x = 5
print(f"x = {x}")
```

> [!tip]- Ответ
> Будет `x = 5`.
