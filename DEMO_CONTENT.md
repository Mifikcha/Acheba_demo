# Учебные модули демоверсии

Демо публикует только заметки из `scripts/demo_manifest.json` и пять собственных страниц навигации. Учебные заметки копируются из Hopes and Dreams; точечные редакторские замены для демо перечислены в `scripts/demo_edits.json`. Полная статья «Движение по окружности» сохраняет порядок объяснения и анимации оригинала; ссылки на отсутствующие темы заменены сообщением о недоступности в демо. Сборка дополнительно исправляет известные короткие ссылки на доступные страницы. Исходные файлы Hopes and Dreams не меняются.

## Учебная последовательность

- **Физика:** пять тем МКТ → соответствующие тренировки → разборы ЕГЭ № 7 и № 8; отдельно — полный урок «Движение по окружности» и справочник размерностей.
- **Математика:** теория функций, разбор № 19 «Параметр» и тренировочные задания по базовой арифметике.
- **Информатика:** главы 02–04 «Истинного фундамента» и разборы ЕГЭ № 2, № 5, № 8 и № 16. Уроки содержат `practice_tasks` и `tests` для Coding Mode.

## Обновление

1. Добавьте точные относительные пути к публичным `.md` в `scripts/demo_manifest.json`. Не добавляйте `private`, личные файлы или каталоги целиком.
2. При необходимости задайте `HND_SOURCE_CONTENT` как путь к каталогу `Публичный сайт` оригинала. На этом компьютере используется `E:\Камень\Hopes and Dreams\Публичный сайт`.
3. Запустите `python scripts/sync_demo.py`. Скрипт скопирует только перечисленные заметки и ресурсы, на которые они ссылаются. Удалённую из списка заметку нужно удалить из демо отдельно.
4. Проверьте соответствие источнику и редакторским заменам: `python scripts/sync_demo.py --check`.
5. Соберите сайт: `npx quartz build -d "Публичный сайт" -o public --concurrency=4`.
6. Запустите `python scripts/fix_demo_links.py`, затем `python scripts/check_demo.py`. Последняя проверка требует точный список опубликованных Markdown-файлов и отсутствие битых локальных ссылок, включая изображения.

`fix_demo_links.py` содержит ограниченный список известных коротких wiki-ссылок из оригинала. При добавлении материалов сначала проверьте, можно ли включить настоящую страницу-пререквизит. Если тема не вошла в демо, замените ссылку в `demo_edits.json` на понятную пометку о недоступности; не копируйте всю библиотеку ради замыкания ссылок.

Coding Mode использует локальные файлы Pyodide 0.26.4 из `quartz/static/pyodide`. Редактор, запуск и проверки обслуживает существующий компонент `python-checker`; обновлять файлы Pyodide нужно комплектом одной версии. Лицензия лежит рядом с ними.

Публикация GitHub Pages запускается только при отправке в `main` или вручную через workflow. Этот локальный перенос не публикуется автоматически.
